# Podtrim で1回分を仕上げる手順

ひまじんプログラマーの1回分を、Podtrim だけで仕上げる手順です（GarageBand は使いません）。かいちさん・のりさん・倉田さんの誰が作っても同じ流れです。詳しい作りは [開発のメモ](development.md) の「編集画面」。

## はじめに一度だけ（その Mac の準備）

1. **Podtrim を入れる**
   - かいちさん・のりさんの Mac には、GitHub の jumpei-kurata/podtrim（公開）を clone して `node app/build.js` で入れます（そこの README.ja.md の「要る物」「入れ方」。2026-10-19）
   - 中で使う道具: ffmpeg（音を変換する道具）と mlx_whisper（文字起こしの道具・Apple のチップの Mac だけ）
2. **説明文を書く AI を選ぶ**（使わないなら飛ばしてよい）
   - おすすめは Gemini（Google・無料枠あり）。鍵（AI を使うための合言葉）を作る:
     1. https://aistudio.google.com/projects を開き、右上の「新しいプロジェクトを作成」で、名前に「Podtrim」と入れて作る
     2. https://aistudio.google.com/api-keys を開き、「API キーを作成」を押す。出た窓のプロジェクトで「Podtrim」を選び、「キーを作成」
     3. できた鍵をコピーする
     - 「課金」（Billing）の設定はしない（無料枠のまま）。鍵は人に送らない・チャットに貼らない
   - Podtrim に入れる: 上の帯の「説明文」→ 下に出た欄の右上の「AI の設定」→「1. 使う AI を選ぶ」で Gemini を押す →「2. 選んだ AI の鍵を貼って『保存』」の欄に貼る →「保存」
   - 鍵は Mac のキーチェーン（パスワードの保管庫）に入り、画面にもファイルにも残りません
   - Gemini の無料枠では、送った文字起こしを Google が改善に使い、人が読むこともあります。気になる時は、有料の Claude・OpenAI か「使わない」を選ぶ（「使わない」でも、文字起こしと「AI に頼む文」まで作るので、Claude などのチャットに貼れば同じ物を書いてもらえます）
3. **CM のフォルダを決める**（決めていなければ `~/Documents/Podcast/CM音声`）
   - 回を開いた後、左の CM の欄の一番下の「フォルダを選ぶ…」で、CM の音が入ったフォルダを選ぶ（その Mac で覚えます）
4. **書き出し先を決める**（決めていなければ `~/Documents/Podcast/書き出し/`）
   - 右上の「書き出す」で開く窓の、書き出し先の右の「変更…」で、書き出したいフォルダを選ぶ（その Mac で覚えます）
   - 録音と同じフォルダを選んでも、録音は消えません。同じ名前のファイルがある時は、その回で前に書き出した物でなければ、置き換えずに止まって「名前を変えてください」と出ます

## 毎回の手順

### ① 録音を用意する

- 収録の頭で「よーおっ」と手拍子をする（3人の録音の頭をそろえるため。はっきりした手拍子なら、手拍子より前も自動で切れます）
- 3人の録音を Mac の「書類」（`~/Documents`）の中に置く。ゲストを呼んだ回（4〜5人）も同じです（録音は2〜8本まで）
- Podtrim は録音を元の場所のまま使います（読むだけ・消さない・動かさない・書き換えない）。編集はすべて回のメモとして別に残り、元の録音はそのままです。書類の外にある時は、Podtrim がコピーを作ります
- **ART19 に上げるまで、録音を動かさない・消さない**（書き出しは元の録音から作るため）

### ② 新しい回を作る

1. 上の帯の左の回の名前を押し、一番下の「＋ 新しい回…（録音を選ぶ）」を押す（⌘N でも同じ）
2. 全員の録音（3人なら3本・ゲストがいれば4〜5本）を、⌘ を押しながらまとめて選んで「開く」（録音を画面に引いて、「新しい回を作る」の所に落としても同じ）
3. 「新しい回を作る」の窓で、回の名前・BGM・CM・間の詰め方を確かめて「作る」
   - BGM と CM は、前の回で使った物が初めから選ばれます。初めての回は「なし」のまま作り、回が開いたら BGM の音を画面に引いて「BGM を入れ替える」の所に落とす（CM も同じ）
   - 間の詰め方は「1.2秒以上の間を、0.4秒に詰めます」のように出ます。初めは前の回で選んだ値です（前の回で選んでいなければ・初めての回は 1.2秒以上を 0.4秒に）。3人以上の回は 1.2秒・0.4秒、2人の回は 1.4秒・0.4秒がおすすめです（2026-10-19 に倉田さんの手編集と比べて決めた）。「詰める間」を左へ動かすほど短い間も詰め（左が 0.6秒・右が 3.0秒）、「残す間」で詰めた後の間の長さを決めます（作った後も「調整」で変えられます）
4. 頭揃え・切る所（黙っている所を詰める）・被りの印・声の大きさ・手拍子より前を切る、まで自動で用意して開きます（40分の回で1分前後の見込み）
   - 頭揃えが自動で決まらなかった時は、「頭を揃える」の窓が開きます（下の「頭を揃える」）
5. 前の回で決めた設定（BGM の音量とフェード・CM の位置とフェード・書き出しの形など）を引き継ぎます（「前の回の設定を引き継ぎました」と出ます）。切った所や音量の線は引き継ぎません

### 頭を揃える（頭揃えが自動で決まらなかった時だけ）

手拍子が小さい・ほかの大きな音に紛れた等で、録音のずれが自動で決まらなかった時は、回をいったん読み込んで「頭を揃える」の窓が開きます（閉じても、上の帯の黄色い「頭を揃える」でまた開けます。揃えるまで「書き出す」は押せません）。

1. 窓には、録音ごとに冒頭 90秒の波形と、手拍子の候補のボタンが並びます（★＝拍手らしい音。「自動で揃わなかった」の札が付いた録音が、選び直す録音です）
2. 「自動で揃わなかった」録音で、手拍子（「よーおっ」の後のパン）のボタンを押す。どれか分からない時は、波形の手拍子らしい所を押す（近くの音に合わせます）
3. 下の「手拍子の前後 1秒」で、全員のパン（とがった山）が真ん中の赤い線にそろっているかを見る。少しずれていたら、そのパンを押すと合わせ直します
4. 「重ねて聞く」で、パンが1回に聞こえるか確かめる（ずれていると「パパン」と2回に聞こえます）
5. 「この揃え方で切る所と被りを探す」を押す。切る所・被りの印・手拍子より前を切る所を探し直して、回を開き直します（40分の回で30秒前後）

### ③ 頭を聞く

- ⏮（Home）で頭に戻り、Space で聞く。話の頭から始まるか
- 手拍子が残っていたら（はっきりしない手拍子だと自動では切れません）: トラックの上で、手拍子のとがった山の少し右から、左の端を越えるまでドラッグ →「3人分消して詰める」（⌘⌫。1人の所だけ選んでも、その時間を全員分消して詰めます）

### ④ 削った所と被りを聞く

1. 上の帯の「✓ 確認」を押す（C）。削った所と被りを、少し前から1か所ずつ自動で聞きます
2. 良ければ「OK」（→）で次へ。← は、聞いている途中なら今の所の頭へ、頭のあたりなら1つ前の所へ戻ります。もう一度は Enter。くり返す（↻）がオンなので、OK を押すまで同じ所をくり返します
3. 直す時:
   - 切りすぎた: 下のトラックの赤い線をダブルクリックで戻す（1人だけ戻すなら、その人の塊の端を外へ引く）
   - 被り（2人が同時に話している所）: 消さなくてよい（両方の声が残ります）。片方だけ消す時は、消す方の範囲を選んで ⌫
   - 大きすぎる所（爆笑など）: 範囲を選んで、下に出たバーの「音量」で下げる
   - 要らない所: 範囲を選んで「3人分消して詰める」（⌘⌫）。1人の所だけ選んでも、その時間を全員分消して詰めます
   - 要らない所（選ばずに）: 要らない所の頭で ⌘T → 終わりでもう一度 ⌘T → そのまま ⌘⌫。再生位置のすぐ左の塊を3人分消して詰めます。間に削った所の印（目盛りの赤・灰色の ▲）があるとそこで止まるので、もう一度 ⌘⌫（押すたびに左へ1つずつ）。「編集後」の並びで使ってください（「元の音」の並びで切る所の中にいる時は使えません）
4. OK は「確認済み」の印を付けるだけで、音は変わりません。間違えたら ⌘Z（300回まで順に戻る・⇧⌘Z でやり直す）。確認済みの所も、上の ‹ › でまた聞けます

- 詰め方を変えたい時は、上の「調整」の「間の詰め方」の「詰める間」（何秒以上の間を詰めるか）と「残す間」のつまみ（新しい回の窓と同じ。「最初の設定に戻す」で回を作った時の値に戻る）
- 何秒前から聞くかは、確認のバーのつまみ（1〜10秒）
- 消す操作は2つだけ覚えれば大丈夫です:
  - ⌫ … 選んだ人の声だけ消す（時間は詰めない＝隙間が残る。1人の咳や物音など）
  - ⌘⌫ … 3人分消して詰める（時間ごと消える）。選んでいれば選んだ時間、選んでいなければ再生位置のすぐ左の塊
  - ⇧⌫ は前からあるキーで、選んでいる時は ⌘⌫ と同じです。戻す時は ⌘Z（削った所・消した所はダブルクリックでも戻ります）。⌘T は切るだけで、何も消えません
- 範囲を選んでいる時のほかのキー: E 選んだ時間を全員分選択（「3人分選択」と同じ）・I フェードイン・O フェードアウト（下のキーの1行にも出ます）
- 保存は自動です（触るたびと、窓を閉じる時）。⌘S は押さなくても大丈夫です（押すと「保存しました」と出ます）。作った説明文も回のフォルダに残り、次に開いた時も出ます

### ⑤ 終わりを聞く

- 本編の終わり（目盛りのオレンジの線）の少し前から聞く。BGM が終わりの3秒で小さくなり、CM が本編の終わりの0.5秒前から重なって入ります
- CM の位置は CM の塊を左右に引く、フェードは塊の上の角を引く、で変えられます

### ⑥ 書き出す

1. 右上の「書き出す」を押す。書き出すのは、全員の声・BGM・CM を混ぜた1本のファイルです（そのまま ART19 に上げられます）
2. 窓で、ファイルの名前（初めは回の名前。例「#508 守り」のように変えてよい・その回で覚えます）・形（WAV か MP3。ART19 はどちらでも上げられる・MP3 は軽い）・音の大きさ（−16 LUFS がおすすめ）・書き出し先（変える時は「変更…」）を確かめて「書き出す」（33分の回で40秒ほど）
   - 「同じ名前のファイルが書き出し先にあります（この回で書き出した物ではありません）」と赤く出た時は、元の録音などを消さないよう止めています。上の「名前」を変えてください（その回で前に書き出したファイルがそのまま残っていれば、置き換えます。同じ名前で別のファイルを置き直した時も止まります）
3. 終わると、窓が閉じて下に説明文の欄が開きます（作り始めはしません。書き出しの結果は欄の上に緑の1行で出ます）。書き出したファイルを聞く時は、説明文の欄の「ART19 と Finder を開く」で Finder が開くので、スペースキーで頭・途中・最後を聞く

### ⑦ 説明文を作る

1. 書き出しの後に開いた説明文の欄（閉じていたら上の帯の「説明文」）の「作る」を押す（文字起こしに2分ほど・そのあと AI が書く）。前に作った下書きがある時は「作り直す」。書き出し直した後の下書きや、今の設定と違うモデルで書いた下書きには、上に青い字で「作り直す」の案内が出ます
2. 黄色の「確かめてほしい所」があれば確かめる
3. 目次の時刻を押すとその所に移るので、話と合っているか聞く
4. タイトル案（4つ・1つ目がおすすめ）から選んで「コピー」。説明文も「コピー」（目次・紹介した物・呼びかけ・最後の決まった文まで全部入ります）。コピーできると、ボタンが少しの間 緑の「✓」になり、上に「コピーしました」と出ます

- タイトルの番号は、番組の RSS のいちばん新しい番号＋1 で入ります（例 #508）
- 欄の上の1行に、どの AI・モデルで書いたかが出ます（例「Gemini（gemini-3.8-flash）」）。今どれで書くかは「AI の設定」の上の1行（例「今は Gemini（gemini-3.8-flash）で書きます」）
- 作れなかった時は、欄に日本語で理由が出ます（鍵が違う・回数の上限・ネット）。前の下書きは残ります

### ⑧ ART19 に上げる

1. 欄の「ART19 と Finder を開く ↗」を押す（ブラウザで番組の管理画面が開き、書き出したファイルが Finder で選ばれた状態で開きます: https://art19.com/admin/series/07ef6b45-d4fc-4d94-b211-e02a27b7e2a6/content ）
2. いつもどおり新しい回を作り、タイトルと説明文を貼る
3. Finder で選ばれているファイルを、ART19 の画面に引いて落とす

### ⑨ 片付け

- ART19 に上げ終わったら、録音を `~/Documents/Podcast/完/` へ（いつもどおり）。Podtrim の回は残しておけます（ただし録音を動かした後は、書き出し直しはできません）
- 要らなくなった回は消せます（1回で約260MB。元の録音の7分の1ほど）: 上の帯の左の回の名前を押して、一番下の「整理する…」→ 消したい回に印を付けて（いくつでも・開かなくてよい）「◯回をゴミ箱に入れる」
  - 消えるのは Podtrim の回のデータ（切った所・波形など）だけです。元の録音と、書き出したファイルは消えません
  - 間違えた時は、Finder のゴミ箱で、知らせに出た名前（例「ep-20261019-133210」）を右クリック →「戻す」。ゴミ箱を空にすると戻せません（空にした時に Mac の空きが増えます）
  - 書き出しや説明文づくりの最中の回は消せません（一覧に「書き出しの最中なので消せません」と出ます）
- 同じ名前の回が並んだ時は、回の名前の後ろに作った日が出ます（例「守りのトークン抑え（10/17）」）

## 困った時

- 間違えた: ⌘Z（300回まで）
- キーの一覧: 上の帯の「?」（? キー）。下の1行（K で出し入れ）にも、その場でよく使うキーが出ます
- 頭揃えが自動で決まらない: 「頭を揃える」の窓で、手拍子を選んで揃えます（上の「頭を揃える」）。手拍子がどの録音にも見当たらない時は、倉田さんに相談
- 説明文が作れない: 欄に出た理由のとおりに（鍵を入れ直す・少し待つ・ネットを確かめる）
